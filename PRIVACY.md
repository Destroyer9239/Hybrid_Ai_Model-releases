# Privacy

Short version: **your chats, files and settings stay on your computer.** The app has no account, no analytics, no tracking and no crash reporting. Anything that leaves your computer does so only because you switched it on for a chat, clicked a button that says so, or because of the update check described below. This page lists every case.

This describes version 0.8.0. It was written from the code, and the "no telemetry" statement below was checked by searching the source for analytics, telemetry and crash-reporting code.

## What stays on your computer

- **Conversations, projects, groups, themes, settings and attachments** are stored on your computer only, in the app's data folder (`%APPDATA%\hybriddesk` on Windows, `~/Library/Application Support/hybriddesk` on a Mac). Nothing is uploaded or synced.
- **Local models** (through Ollama, or a local image server you run) answer on your computer. A chat set to this computer only never contacts a cloud service.
- **Hardware checks** (processor, free memory, free disk space, NVIDIA GPU memory) run locally and are shown only to you.
- **Voice input** is transcribed on your computer by the Whisper speech model that ships inside the app. The recording is never sent anywhere, and the app's own web page is blocked from the network.
- **Saved keys** (the paid OpenAI API key, Brave and Tavily search keys) are encrypted with your operating system's secure storage (Windows credential encryption, the macOS Keychain). They are never written to logs, chats or the problem report.
- **Reading and editing your files** happens only in a project folder you choose, with the permissions you set. Edits and commands wait for your approval.

## No telemetry

The app has no analytics, usage tracking, advertising identifiers or crash reporter. There is no account to create. The app's own page cannot make network requests at all. The "Report a problem" page in Settings > About only builds text for you to copy: it includes the version, your operating system, hardware, the state of local AI, model names and the last error messages, with your home folder replaced by `~` and anything key-like removed. It contains no chat text, file names, keys or e-mail addresses, and nothing is sent unless you paste it into an issue yourself.

Electron (the browser engine the app is built on) and the programs the app starts, such as Ollama and the GitHub CLI, are separate software with their own behaviour; this page covers what Hybrid AI Model itself does.

## Removing your data

Uninstalling asks whether to delete conversations, settings and the saved API key (the default keeps them). To remove everything by hand, delete the data folder named above. Models downloaded by Ollama live in Ollama's own folder and are removed in Settings > Local AI or by uninstalling Ollama.
